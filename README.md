# Interactive Card Game Robot

*Computer Vision Project*

## Project Overview

A fully functional interactive system that combines computer vision, machine learning, and hardware integration to create an autonomous card game playing robot. The system demonstrates real-time image processing, multi-modal recognition, and human-robot interaction capabilities.

## System Capabilities

### Multi-Modal Recognition
- **Card Recognition**: Real-time identification of playing cards using computer vision
- **Face Recognition**: Player identification and tracking for game state management
- **Gesture Recognition**: Hand gesture interpretation for game commands and interactions

### Interactive Features
- Autonomous card game playing with decision making
- Natural human-robot interaction through gesture and facial recognition
- Real-time feedback and game state communication
- Adaptive behavior based on player actions and preferences

### Computer Vision Pipeline
- **Registration**: Each player's face is registered before playing
- **Preprocessing**: Real-time image enhancement and noise reduction
- **Feature Detection**: Robust extraction of card features, facial landmarks, and hand gestures
- **Classification**: Machine learning models for accurate face and gesture recognition. Traditional computer vision methods for card recognition.

### Hardware Integration
- **Camera Systems**: Two camera angles card recognition as well as face/gesture recognition
- **Processing Unit**: Real-time computation for vision and control algorithms
- **User Interface**: Visual and audio feedback systems

## Core Technologies

### Software Stack
- **Python** - Primary development language for flexibility and ML libraries
- **OpenCV** - Computer vision algorithms and image processing
- **NumPy** - Numerical computations and array operations
- **Machine Learning Libraries** - Mediapipe

### Computer Vision Techniques
- Contour detection and shape analysis for card identification
- Template matching and feature matching algorithms
- Deep learning methods for face and gesture recognition

## Relevant Skills 

- **Computer Vision**: Advanced image processing and object recognition
- **Python Programming**: Complex system integration and real-time processing
- **Hardware Integration**: Bridging software algorithms with physical systems
- **System Design**: End-to-end solution architecture and implementation
